# Data Analysis Mastery

A structured, hands-on learning journey into Data Analysis,
Statistics, Research Methodology, and analytical tools.

## About This Repository

This repository documents my journey from beginner to
advanced-level data analysis, with a focus on academic
research and practical analytical skills.

## Learning Objectives

- Understand data analysis and research methodology.
- Learn descriptive and inferential statistics.
- Work with Excel, SPSS, Jamovi, and JASP.
- Develop skills in Python, R, and SQL.
- Perform quantitative and qualitative data analysis.
- Create visualizations and interactive dashboards.
- Interpret and report research findings using APA 7.
- Build reproducible, practical data analysis projects.

## Tools and Technologies

- Microsoft Excel
- IBM SPSS Statistics
- Jamovi and JASP
- Python and Jupyter Notebook
- R and RStudio
- SQL
- Power BI and Tableau
- NVivo and other qualitative analysis tools

or appropriately anonymized. Private research data
and personally identifiable information will not
