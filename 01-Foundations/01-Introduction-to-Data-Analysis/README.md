## Part 1: What is Data?

### Definition

Data refers to collected facts, observations,
and measurements about people, objects, or events.

### Main Types of Data

**Quantitative Data**
- Numerical information.
- Examples: Age, marks, study hours.

**Qualitative Data**
- Categorical or descriptive information.
- Examples: Faculty, preferred platform, satisfaction level.

### Why Data Matters in Research

Data provides evidence that helps researchers
answer research questions and interpret findings.

## Part 2: What is Data Analysis?

### Definition

Data analysis is the process of inspecting, cleaning,
organizing, transforming, and interpreting data to
discover useful information.

### Three Important Concepts

1. Data Collection - Gathering information.
2. Data Analysis - Examining and processing data.
3. Data Interpretation - Understanding the results.

### Example

Research topic:
The Relationship Between Social Media Usage
and Academic Performance Among University Students.

### Common Data Analysis Tools

- Microsoft Excel
- IBM SPSS Statistics
- Jamovi
- Python
- R
- Power BI
- NVivo
